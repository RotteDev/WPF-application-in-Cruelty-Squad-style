# A Corporate-Bureaucratic Application

A surreal, immersive WPF desktop application inspired by the visual and audio style of Cruelty Squad. This project was created in 3 days. It is not a game or an application that we are used to. I wanted to repeat the rhetoric and style of Consumer SoftProducts. There is a small mini-plot here, but no more.

## 🛠 Tech Stack
- C# / WPF (.NET 8 / 10)
- WpfAnimatedGif for UI animations
- Custom MediaPlayer audio management
- Win32 API integration for cursor handling

*All assets were taken from the Cruelty Squad.*\
*Warning: The application contains flashing images and loud sounds.*
